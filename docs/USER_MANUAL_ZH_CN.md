# Pitch Curve 0.7.22 用户说明书

适用版本：Pitch Curve 0.7.22
文档语言：简体中文

## 1. 产品简介

Pitch Curve 是一款用于提取和迁移细微音高变化的音频效果插件。它可以：

1. 从一段参考音频中学习音高变化曲线。
2. 将学习到的曲线施加到当前 DAW 轨道中的声音。
3. 允许用户直接用鼠标绘制或修改音高变化曲线。

Pitch Curve 提取的是相对于参考音频中位音高的变化量，而不是参考音频的绝对音高。因此，目标声音会保留自身音区，只继承参考音频中的颤音、滑音和其他细微音高运动。

## 2. 当前支持的平台和格式

### Windows

- Windows 10 或 Windows 11，64 位。
- VST3 插件。
- 64 位独立运行程序。
- 当前公开安装包为 Windows x64 版本。
- Windows ARM 设备可尝试通过系统的 x64 模拟层运行；原生 ARM64 版本需单独构建。

### macOS

项目支持构建：

- VST3
- Audio Unit（AU）
- 独立运行程序
- Intel 与 Apple Silicon Universal Binary

本说明书附带的安装包仅为 Windows x64 版本。

## 3. 安装

### 3.1 安装前

安装或升级前，请关闭：

- 所有 DAW。
- Pitch Curve 独立运行程序。
- 插件扫描器。
- 任何正在使用 Pitch Curve VST3 的音频程序。

Windows 在程序或 DAW 已加载插件时会锁定对应文件。如果没有关闭这些程序，安装器可能提示“无法打开要写入的文件”。

### 3.2 安装步骤

1. 运行 `Pitch-Curve-0.7.22-Windows-x64.exe`。
2. 根据 Windows 提示授予管理员权限。
3. 完成安装。
4. 重新打开 DAW，并执行一次插件重新扫描。

默认安装位置：

- VST3：`C:\Program Files\Common Files\VST3\Pitch Curve.vst3`
- 独立程序：`C:\Program Files\Circus Audio\Pitch Curve\Standalone\Pitch Curve.exe`

### 3.3 Windows 安全提示

当前开发安装包尚未使用 Authenticode 证书签名，因此 Windows SmartScreen 可能显示“未知发布者”提示。请只使用可信来源提供的安装包，并使用随安装包提供的 `.sha256` 文件核对 SHA-256。

## 4. 界面说明

### 4.1 Learn 区域

界面上方是参考音频区域，包含：

- `DROP AUDIO OR BROWSE`：拖入音频，或打开文件选择器。
- `No Audio File`：表示当前尚未选择参考音频，使用比按钮稍大的字体。
- 音频波形：选择文件后显示参考音频波形。
- `LEARN CURVE`：分析参考音频并生成音高变化曲线。与 DROP、CLEAR 使用相同按钮风格；未选择音频时保持清晰的停用状态。

支持的参考音频格式：

- WAV
- AIFF / AIF
- FLAC
- MP3
- OGG

### 4.2 曲线编辑器

中央曲线编辑器显示音高变化：

- 横轴：参考音频时间。
- 纵轴：音高变化，单位为 semitone（半音，界面缩写为 `ST`）。
- 中心线：0 半音。
- Amount 为 0% 时，纵轴顶部和底部都显示 0 半音，曲线变为灰色，实际处理量为零。
- Amount 为 100% 时，纵轴显示 ±6 半音。
- Amount 为 200% 时，纵轴显示并限制在最大 ±12 半音。
- 其他 Amount 数值下，左侧刻度会随旋钮连续变化。
- 绿色竖线：当前播放位置。

曲线会按设置的时长循环。DAW 停止播放时，绿色播放线会立即回到曲线开头；下次开始播放时会从开头按真实时间匀速运行，不受 DAW 启动预缓冲速度影响。

### 4.3 时间控制

右侧上方的时间圆环旋钮用于设置整条曲线从开头播放到结尾所需的时间，旋钮下方提供两个可直接输入的时间框：

- `SECOND`：秒数。
- `FRAME`：帧数，固定使用 30 FPS。
- 拖动时间旋钮时，SECOND 和 FRAME 会同步更新。
- 修改 SECOND 或 FRAME 后，时间旋钮也会同步更新。
- 例如 `3 SECOND + 15 FRAME` 等于 3.5 秒。
- 输入 30 帧或更多时会自动换算并进位到秒；例如 `2 SECOND + 45 FRAME` 会变成 `3 SECOND + 15 FRAME`。
- 最短时长为 1 帧，最长时长为 60 秒。旋钮在常用的短时长区域提供更细的调整精度。
- 点击时间旋钮右上方的小锁可锁定时长；锁定后旋钮及 SECOND、FRAME 输入框均不可修改。
- 时长锁定时执行 Learn Curve 只替换音调曲线，不会改变当前时长。
- 再次点击小锁即可解锁；锁定状态会随 DAW 工程一起保存和恢复。

### 4.4 Amount

`AMOUNT` 控制曲线施加深度：

- `0%`：不施加音高变化，使用延迟匹配的旁路。
- `100%`：按原始曲线深度处理。
- `200%`：将曲线变化量放大一倍。

双击旋钮可恢复为 100%。

### 4.5 Smooth

`SMOOTH` 是 0–10 的整数步进旋钮：

- 默认值为 `5`。
- `0`：保留原始的连续折线，不添加矩形或阶梯纹理。
- `1–9`：逐级增加固定局部窗口和混合强度，只圆润当前位置附近的折点与肩部。
- `10`：使用最大局部窗口，但影响仍限制在当前位置附近，不会牵动远处曲线。

算法会根据局部音高范围自动降低峰值和谷值处的平滑权重，因此 Smooth 主要改变折点附近的形状，对振幅的影响较小。0–10 的局部窗口跨度已扩大，使各档变化更易观察。输出始终限制在局部原始范围内，不会产生过冲。鼠标编辑与 Smooth 都采用固定局部范围，远处曲线不会因局部描绘或动态峰谷判定而突然变化。

### 4.6 Clear Curve

点击 `CLEAR CURVE` 可删除当前曲线。双击曲线编辑区域不会清空曲线。

## 5. 快速使用流程

### 5.1 从参考音频学习

1. 在 DAW 中，将 Pitch Curve 插入需要处理的目标音频轨道。
2. 将一段参考音频拖入 Learn 区域，或点击 `DROP AUDIO OR BROWSE`。
3. 确认文件名和波形显示正确。
4. 点击 `LEARN CURVE`。
5. 等待状态栏显示参考频率、音频时长和学习结果。
6. 播放目标轨道。
7. 使用 `AMOUNT` 调整效果强度。

建议优先使用：

- 单声部人声。
- Bass。
- Lead。
- 独奏乐器。
- 没有和弦、叠唱或复杂混响的素材。

### 5.2 手动绘制曲线

1. 在曲线编辑器中按住鼠标左键。
2. 沿需要的音高走向拖动。
3. 可以反复修改不同时间位置。
4. Learn 生成曲线后仍可继续自由绘制。

学习得到的检测点在首次手绘时会转换为均匀编辑网格，确保鼠标横向位置与曲线修改位置一致。

### 5.3 只使用手绘

不需要加载参考音频。直接在空曲线区域中拖动鼠标，即可创建一条新的曲线。

## 6. 音高学习原理

Pitch Curve 使用面向单声部素材的音高检测：

1. 将输入转换为单声道分析信号。
2. 检测每个时间帧的基频和置信度。
3. 过滤不稳定检测结果。
4. 使用中位数降低偶发跳点。
5. 以参考音频的中位音高为中心，将结果转换为 cent。

这样可以保留目标声音的原始音区，只迁移相对音高运动。

高采样率音频会先转换到适合分析的采样率，以提高 96 kHz、192 kHz 文件中低音检测的准确性。

## 7. 文件和分析限制

为了避免异常文件消耗过多内存或阻塞 DAW：

- 最多分析 60 秒音频。
- 最多解码 12,000,000 个采样。
- 支持的文件采样率范围为 8 kHz 至 768 kHz。
- 状态数据最大为 2 MiB。
- 曲线最多保存 4,096 个点。
- 非法、非有限和超出范围的数据会被丢弃或限制。

长于分析上限的音频只分析前面的有效部分。

## 8. DAW 行为

### 8.1 延迟补偿

Pitch Curve 使用高质量频谱移调算法，因此会产生固定处理延迟。插件会向 DAW 正确报告完整延迟。

支持插件延迟补偿（PDC）的 DAW 会自动对齐轨道。即使没有曲线或 Amount 为 0%，插件也保持相同延迟，避免播放过程中切换曲线时改变 DAW 的补偿状态。

### 8.2 宿主 Bypass

宿主 Bypass 使用延迟匹配路径，避免旁路前后出现时间偏移。切换处理状态时使用短交叉淡化，以降低咔嗒声和瞬态。

### 8.3 工程保存

以下内容会随 DAW 工程保存：

- Amount 参数。
- 当前曲线。
- 曲线时长。

参考音频本身不会复制到 DAW 工程状态中。

## 9. 状态提示

常见提示包括：

- `Draw a curve, or learn one from audio`：等待绘制或加载音频。
- `No Audio File`：尚未选择参考音频。
- `Ready to analyse`：文件已加载，可以开始学习。
- `Listening for pitch movement...`：正在分析。
- `No stable pitch found - try a monophonic source`：未检测到稳定单音高。
- `Curve cleared - draw or learn a new contour`：曲线已清空。

## 10. 故障排查

### 安装器提示“无法打开要写入的文件”

原因通常是旧版插件仍被占用。

处理方法：

1. 关闭 DAW。
2. 关闭 Pitch Curve 独立程序。
3. 在任务管理器中关闭 DAW 的插件扫描器或后台进程。
4. 重新运行安装器。
5. 如果仍然失败，重启 Windows 后再安装。

### DAW 找不到插件

1. 确认 VST3 文件位于：
   `C:\Program Files\Common Files\VST3\Pitch Curve.vst3`
2. 在 DAW 中执行完整插件重扫。
3. 确认 DAW 为 64 位并支持 VST3。
4. 检查 DAW 的插件黑名单。

### 文件有波形，但 Learn 没有生成曲线

可能原因：

- 文件为和弦或多声部。
- 背景噪声太大。
- 音量过低。
- 混响或延迟过强。
- 音高超出稳定检测范围。

建议换用干净、清晰的单声部素材。

### Learn 后手绘位置不准确

0.4.2 已修复学习曲线点分布不均造成的位置错位。请确认安装的是 0.4.2 或更新版本，并让 DAW 重新扫描插件。

### 界面出现乱码

0.4.1 起，界面状态文本使用兼容性更高的字符。若仍看到乱码：

1. 确认旧版 VST3 已被新版本覆盖。
2. 清除 DAW 插件缓存并重新扫描。
3. 重启 DAW。

### 听到音色变化或处理伪影

任何实时移调算法都无法保证对所有声音完全无伪影。建议：

- 使用适度的曲线幅度。
- 降低 Amount。
- 避免处理完整混音、和弦或强瞬态素材。
- 对人声、Bass、Lead 和独奏乐器分别测试。

## 11. 卸载

1. 关闭 DAW 和 Pitch Curve。
2. 打开 Windows“设置”。
3. 进入“应用”或“已安装的应用”。
4. 找到 `Pitch Curve 0.7.22`。
5. 点击“卸载”。

卸载器会删除独立程序、VST3 和卸载注册信息。

## 12. 隐私与安全

Pitch Curve：

- 不联网。
- 不上传音频。
- 不包含遥测。
- 不访问账号或凭据。
- 不执行更新程序。
- 只读取用户主动选择或拖入的音频文件。

参考音频分析在本机完成。

## 13. 当前限制

- 音高学习主要面向单声部素材。
- 不支持从和弦中分离多个独立音高曲线。
- 曲线基础编辑范围为 ±6 半音，Amount 200% 时最大输出为 ±12 半音。
- 当前提供的 Windows 安装包为 x64。
- 开发安装包尚未进行 Authenticode 签名。
- 尚不能保证所有 DAW、声卡、采样率和音频素材都没有算法伪影。

## 14. 版本要点

Pitch Curve 0.7.22 包含：

- Smooth 重新设计为固定局部窗口算法，不再依赖可能跳变的全局峰谷锚点。
- 局部范围门控保护峰谷振幅和波形相对关系，并将结果限制在原始局部范围内。
- Smooth 0–10 使用步进式感知强度，局部影响范围有明确上限。
- 界面与实际音调处理共用同一平滑函数，避免视觉和声音变化不一致。
- 保留 0.7.12 的曲线手绘方式，不引入后续被否定的曲线交互变化。
- 工程状态在 XML 解析前检查体积、节点数、嵌套深度，并拒绝 DTD 与实体声明。
- 修正实时曲线缓冲发布顺序，避免音频线程等待尚未完成发布的数据槽。
- 移除实时音频线程中的高斯卷积，改用计算量更低的保形插值。
- Learn 开始时重新核对文件，并在分析期间暂时锁定曲线与 Clear，避免异步结果覆盖同期编辑。
- 降低音高分析过程中的内存复制；读取失败与“未检测到稳定音高”使用不同提示。
- 修复独立运行程序被错误识别为停止播放、曲线无法正常前进的问题。
- Windows 旧版本清理移到写入新文件之前，卸载只删除本版本拥有的 VST3。
- 开锁锁梁移除翘起末端，锁图标轻微缩小并下移；未锁颜色轻微降低亮度。
- 锁定时仅改变锁图标，时间旋钮及 SECOND、FRAME 外观保持不变。
- SECOND 与 FRAME 数字基线微调，与 Amount、Smooth 视觉居中一致。
- 时长锁缩小并移到时间旋钮外侧右上方，开锁造型更清晰。
- SECOND、FRAME、Amount 与 Smooth 数值框的数字统一居中。
- 可保存状态的时长锁在锁定后让 Learn Curve 保留当前时长。
- Smooth 1–10 逐级圆润折点，同时保持控制点振幅与相对关系。
- 音频处理直接跟随界面所示平滑曲线，不再叠加隐藏的 25 ms 音高缓动。
- Windows 开始菜单文件夹默认使用厂商名称 `Circus Audio`。
- Smooth 0 改为连续折线，移除矩形阶梯纹理。
- Smooth 1–10 使用逐级增强的保形曲线混合，级别差异清晰自然。
- 更安全的实时曲线缓冲发布协议。
- 受 60 秒与采样数量限制保护的波形预览。
- 反相立体声和检测频率边界修复。
- 修复首次播放时播放线可能从曲线后段开始的问题。
- 左侧刻度改为随 Amount 变化的半音单位。
- 最大音高处理范围调整为 ±12 半音。

- `No Audio File` 空状态。
